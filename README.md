# حاسبة أقساط التمويل | شركة تساهيل (Tasaheel Loan Calculator)

تطبيق ويب تفاعلي حديث ومخصص لحساب أقساط التمويل لمشروعات وأنشطة عملاء **شركة تساهيل للتمويل** (https://tasaheelfinance.com)، متوافق كلياً مع أنظمة السداد الشهرية والموسمية والفائدة الثابتة والمتناقصة.

---

## 🌟 المميزات الرئيسية
- 🟢 **مطابقة الهوية البصرية لتساهيل**: درجات اللون الأخضر البترولي (#0B7A5A) والبرتقالي الذهبي (#F5A623) مع خط القاهرة (Cairo) الأصيل.
- 📱 **واجهة مستخدم عربية كاملة RTL**: تصميم متجاوب فائق السرعة على جميع الهواتف الذكية والأجهزة اللوحية وأجهزة الحاسوب.
- 💰 **نطاق تمويل مرن**: من 5,000 جنيه مصري حتى 15 مليون جنيه مع أزرار اختيار سريعة ومؤشر تفاعلي.
- 📊 **دعم كامل لنظامي السداد**:
  - **السداد الشهري**: من شهر إلى 36 شهراً (حتى 3 سنوات) مع أزرار للمدد الشائعة.
  - **السداد الموسمي**: تحديد فترة السداد الكلية وعدد الدفعات مع حساب دورية السداد تلقائياً (مثال: دفعة كل 4 شهور).
- 📈 **طريقتين لحساب الفائدة**:
  - **فائدة ثابتة (Flat Rate)**: النظام الافتراضي في التمويل متناهي الصغر.
  - **رصيد متناقص (Reducing Balance)**: وفق معادلة الإهلاك المالي القياسية (Amortization PMT).
- 📋 **جدول سداد تفصيلي (Amortization Schedule)**: جدول قابل للطي يوضح رقم القسط، تاريخ الاستحقاق، جزء الفائدة، أصل المبلغ، والرصيد المتبقي.
- ⚡ **أدوات مشاركة سريعة**:
  - زر **نسخ النتيجة**: لنسخ ملخص جاهز للمشاركة عبر الواتساب والبريد.
  - زر **طباعة / حفظ PDF**: تنسيق طباعة خاص ومنسق بدون إظهار أزرار التحكم.
  - رابط مباشر لتقديم طلب التمويل عبر الموقع الرسمي لشركة تساهيل.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS مع متغيرات ألوان CSS المخصصة
- **Icons**: Lucide React
- **Typography**: Google Font (Cairo)
- **Testing**: Vitest

## 🚀 التثبيت والتشغيل محلياً

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل خادم التطوير (Run Development Server)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 3. تشغيل اختبارات الوحدة (Run Unit Tests)
```bash
npm run test
```
أو وضع المراقبة:
```bash
npm run test:watch
```

### 4. بناء نسخة الإنتاج (Build Production Bundle)
```bash
npm run build
```
ولتشغيل نسخة الإنتاج:
```bash
npm start
```

## 🧪 حالات الاختبار المضمنة (Unit Tests)
يحتوي الملف `__tests__/calculate.test.ts` على اختبارات مؤكدة بنسبة 100%:
1. **تمويل 100,000 ج.م** بفائدة 24% سنوية، سداد شهري على 12 شهر، فائدة ثابتة:
   - القسط = 10,333.33 ج.م | إجمالي الفائدة = 24,000 ج.م | إجمالي المسدد = 124,000 ج.م
2. **تمويل 200,000 ج.م** بفائدة 20% سنوية، سداد موسمي على 12 شهر مقسمة 3 دفعات (دفعة كل 4 شهور)، فائدة ثابتة:
   - القسط = 80,000 ج.م | إجمالي الفائدة = 40,000 ج.م | إجمالي المسدد = 240,000 ج.م
3. **تمويل 50,000 ج.م** بفائدة 18% سنوية، سداد شهري على 36 شهر، رصيد متناقص:
   - القسط = 1,807.62 ج.م | إجمالي الفائدة = 15,074.31 ج.م | إجمالي المسدد = 65,074.31 ج.م

4. انقر على **"Deploy"**. سيتم البناء والنشر في ثوانٍ معدودة.
